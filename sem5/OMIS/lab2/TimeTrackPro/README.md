# TimeTrackPro

Лабораторная работа № 2 по объектному моделированию интеллектуальных систем. TimeTrackPro учитывает рабочие смены, согласует отсутствия и формирует месячный табель. Приложение использует Python, Streamlit и SQLite.

## Запуск 

1. Откройте в VS Code папку `TimeTrackPro`, где находятся `app.py` и `.vscode/launch.json`.
2. Установите расширения Microsoft **Python** (`ms-python.python`) и **Python Debugger** (`ms-python.debugpy`). Требуется Python 3.11 или новее.
3. В терминале VS Code создайте окружение и установите зависимости.

   Linux и macOS

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   python3 -m pip install -r requirements.txt
   ```

   Windows PowerShell

   ```powershell
   py -3 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   ```

4. Откройте палитру команд через **Ctrl+Shift+P**, выберите **Python: Select Interpreter**, затем интерпретатор из `.venv` (`.venv/bin/python` или `.venv\Scripts\python.exe`).
5. Откройте **Run and Debug → TimeTrackPro** и нажмите **F5**. Приложение доступно по адресу [http://localhost:8501](http://localhost:8501).

Из активированного окружения можно запустить приложение напрямую.

```bash
python3 -m streamlit run app.py
```

При первом запуске рядом с `app.py` создаётся `timetrack.sqlite3` с демонстрационными данными. Для другой базы укажите её путь в переменной окружения `TIMETRACKPRO_DB`.

## Сценарии

### Сотрудник

1. Войдите как `employee`. Откройте **Отметить время** и нажмите **Начать**. Нажмите **Завершить** и проверьте обе отметки в истории. Если смена короче перерыва, система запишет ноль часов.
2. Нажмите **Назад** и откройте **Мой график**. Чтобы посмотреть другую неделю, нажмите на заголовок графика и укажите дату.
3. Вернитесь в кабинет, откройте **Заявка на отпуск**, выберите вид отсутствия, заполните даты в пределах одного года и отправьте заявку. После отправки откроется кабинет.
4. Нажмите на строку **Вы вошли как** и откройте **Мои заявки**. Здесь видны статусы и уведомления. Для проверки согласования выйдите из кабинета и войдите как руководитель.

### Руководитель

1. Войдите как `manager`, откройте **Посещаемость отдела** и нажмите **История** у сотрудника. Панель с завершёнными сменами откроется под списком.
2. Вернитесь в кабинет и откройте **Согласовать заявки**. Утвердите заявку или отклоните её, указав причину. Результат появится в кабинете сотрудника.
3. Откройте **Сформировать график**. Нажмите на поле периода, укажите даты и примените их. Нажмите на строку времени под именем сотрудника, чтобы выбрать шаблон, затем сохраните график.

### HR-администратор

1. Войдите как `hradmin`, откройте **Справочник сотрудников** и выполните поиск по ФИО или отделу. **Профиль** и **Редактировать** раскрывают соответствующую панель под списком. Можно также добавить сотрудника с любой из трёх ролей.
2. Вернитесь в кабинет и откройте **Формирование табеля**. Табель за текущий месяц формируется при открытии экрана. Чтобы сформировать его за другой месяц, нажмите **Период**, выберите месяц и нажмите **Сформировать табель**.
3. Нажмите **Корректировка**, выберите сотрудника и сохраните итоговые часы. Нажмите **Excel**, чтобы скачать файл XLSX с нормой, фактом, отсутствиями и корректировками.
4. Откройте **Системные настройки**, измените переключатели и сохраните. Чтобы настроить время типового графика, нажмите **Активных графиков** в кабинете.

## Правила учёта

- Время и даты смен определяются в часовом поясе Минска. Длительность завершённой смены учитывает установленный перерыв.
- Отпуск списывается в календарных днях после утверждения. Норма табеля учитывает утверждённые отсутствия в рабочие дни.
- Обычный и гибкий шаблоны применяются с понедельника по пятницу, сменный — со вторника по субботу. Руководитель назначает шаблон на период, HR задаёт часы и длительность перерыва.
- Саморегистрация создаёт аккаунт сотрудника в отделе продаж. Отдел и привилегированные роли назначает HR при создании аккаунтов.
- Переключатель переработок влияет на табель. Почта, напоминания, 2FA и турникеты представлены сохраняемыми параметрами прототипа.
